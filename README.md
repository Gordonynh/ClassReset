# 课后自动复原

下课一段时间后，如果电脑没回到干净状态，就全屏倒计时提示，没人拦就自动收拾。

## 什么时候触发

下课满一段时间（默认 15 秒，可调）后检查。满足任意一条就提示：

- 任务栏上还有窗口没关
- 窗口标题或进程名命中关键词（默认 `Hite`、`WPS`、`Seewo`）
- 桌面布局和录入的基线对不上
- 有 U 盘没弹出

**连堂课跳过**：下节课和上节课是同一科目时不收拾。但如果两节课之间跨过了 **13:00**（可调），
说明中间隔了午休那么久、教室可能被别人用过，照常收拾。

## 提示

全屏淡灰色遮罩：**即将还原系统　点击屏幕以取消**，10 秒倒计时。
点屏幕任意位置或按任意键即取消。倒计时走完才动手。

## 收拾什么

| 动作 | 说明 |
|---|---|
| 关闭任务栏软件 | 只关**任务栏上看得见**的程序 |
| 弹出 U 盘 | 只弹可移动卷 |
| 桌面复原 | 新增文件移到回收站 + 图标位置摆回基线 |

## 安全设计

这个插件会结束进程、弹设备、删文件，所以每一处都按「宁可漏做也不做错」来设计。

**关软件**

- 只处理任务栏窗口（标准的 Alt+Tab 判据：排除工具窗口、无标题窗口、被 DWM cloak 的挂起 UWP、
  以及归属于别人的附属窗口）。后台服务、托盘程序、其它插件的浮窗天然不在范围内
- `explorer` **只关窗口，绝不结束进程**
- 内置硬保护名单（用户改不掉）：系统外壳与核心进程、输入法、远程控制软件、任务管理器、
  以及任何位于 Windows 目录下的程序、ClassIsland 自己
- 先发 `WM_CLOSE` 让程序自己退（未保存的文档照常弹提示），等宽限期后仍在才强制结束

**弹 U 盘**

- 只处理 `DriveType.Removable` 的卷。键鼠、摄像头这些根本不是卷，进不了范围
- 加锁失败（盘里还有文件开着）就直接放弃并报出是哪个盘，**绝不强行卸载**

**桌面**

桌面这块的保险最多，因为这台机器的桌面是 `C:\Mac\Home\Desktop` —— 一个指向 Mac 宿主机的
Parallels 共享目录，里面约 217 GB / 22.8 万个文件，而且**这个路径不支持回收站**。
只要在共享盘短暂掉线时录了基线，等盘回来所有东西都会被判成「新增」。所以：

- **没录基线就什么都不做**
- 录基线时如果一个项目都读不到（盘掉了），拒绝录入
- 基线绑定机器名 + 用户 SID + 桌面路径，任一不符直接放弃
- **数量熔断**：新增项超过设定的上限（默认 25）就只上报不删除
- 默认走回收站，删了能找回；回收站用不了时只上报，除非明确开了「直接删除」
- 文件夹要单独开开关，而且真删之前先递归数一遍，过大直接跳过
- 单个文件超过 200 MB 不动
- 只比对第一级，文件夹里面怎么变都不管

### 删除方式

默认把新增文件移入回收站。设置里有「**直接删除，不放入回收站**」——
开了就是永久删除、找不回来，默认关。

之所以要这个开关：回收站不是随处可用的，而老版本一旦判定「不支持回收站」就整批放弃，
表现成清理从来不生效。现在改成**先试回收站，失败再按开关决定要不要退到直接删除**，
判定本身也从「拦住一切」降级成一条提示。

> 真正拦住误删的从来不是这个开关，而是上面那串闸——尤其是基线的身份绑定。
> 删除方式只决定「删了能不能找回」，决定「删不删」的是它们。

## 设置

**应用设置 → 课后自动复原**。可以调触发延迟、倒计时长度、连堂判定、各项开关、
永不关闭的程序名单、触发关键词，也可以在那里录入桌面基线、看当前会不会触发、演练一次。

「演练一次」会正常弹倒计时，但确认后只报告「会关掉什么」，不真动手。

「**立即执行**」则会真的执行，用来在装好之后验一遍。它不受启用开关约束——
手动按下就是明确的意图，正好用于在没开自动重置的机器上先试一次再决定要不要开。

### 取消之后会再问一次

取消常常不是「不要执行」，而是「现在不方便」。所以被取消后会隔一段时间重试
（默认 3 分钟，最多 2 次，都可调）。重试前重新判定一次：已经收拾干净、或者又上课了，
就不再打扰。

### 关机与下课重置不再打架

两者都用同一个全屏遮罩，而遮罩是单例——后来的一弹，前一个就被当成「用户取消」收掉。
12:30 这种既是关机点又正好是下课点的时刻，关机倒计时刚出来十几秒就被下课重置顶掉，
日志里留下一条「定时关机已取消」，关机再也不会发生。

现在倒计时一开始就占住流程，同级流程不再插队；关机比重置高一档，
可以接管正在倒计时的重置——关机流程本身就先跑一遍重置，接管不会少做任何事。
